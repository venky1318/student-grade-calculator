# Student Grade Calculator

## Project Overview
The Student Grade Calculator is a Python program that assigns grades based on student marks out of 100.

## Objective
To apply Python conditional statements and input validation to automate a basic student grading process.

## Technologies Used
- Python 3
- Visual Studio Code
- GitHub

## Grading Criteria

| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–less than 90 | B |
| 70–less than 80 | C |
| 60–less than 70 | D |
| 0–less than 60 | F |

## Features
- Accepts a student's name and marks.
- Assigns a grade automatically.
- Validates marks between 0 and 100.
- Handles invalid numeric input.
- Displays the student's name, marks, grade, and status.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the folder in VS Code.
4. Run `python student_grade_calculator.py` in the terminal.

On Windows, you can also use `py student_grade_calculator.py`.
